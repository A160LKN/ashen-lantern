# Регрессионный чек-лист по механикам

## Управление
- [x] WASD и стрелки — движение (авто: WASD; стрелки не проверялись отдельно)
- [x] Shift — бег быстрее шага (авто)
- [x] Выносливость убывает при беге, восстанавливается после паузы (авто)
- [x] Удар невозможен при выносливости < 5 (авто)
- [x] ЛКМ — удар в сторону курсора (авто)
- [x] E — взаимодействие с ближайшим объектом (авто: NPC, дверь, маяк)
- [x] Q — выпить зелье; при полном здоровье — отказ без траты (авто)
- [x] I — инвентарь (авто); [ ] Tab — инвентарь
- [x] Клавиши не «залипают» после паузы (авто); потеря фокуса окна — сброс клавиш реализован

## Бой и враги
- [x] Числа урона, криты жёлтым (вручную)
- [x] Слизень прыгает, скелет бьёт мечом, дух стреляет (вручную; атака скелета — авто)
- [x] Враг замечает героя («!») и преследует (вручную)
- [x] Враг теряет героя и возвращается к месту патруля (авто)
- [x] После удара по герою 0,85 с неуязвимости (авто)
- [x] Босс: пробуждение, удар по земле, огненное кольцо, призыв, рывок (вручную, по состояниям ИИ)
- [x] Смерть босса без ошибок, выпадает осколок (авто)

## Мир и предметы
- [x] Ключ открывает дверь, ключ тратится (авто)
- [x] Дверь без ключа — отказ (авто)
- [x] Сундук открывается один раз (вручную)
- [x] Горшок разбивается ударом, клетка освобождается (авто)
- [x] Монеты притягиваются и не улетают (авто + юнит)
- [x] Лут не падает в стены (юнит)
- [x] Лимит 9 зелий, сообщение о полной сумке (вручную)
- [x] Масло убывает, радиус света уменьшается, предупреждение ниже 15% (авто)

## Прогрессия
- [x] Опыт → уровень → полное здоровье (юнит)
- [x] Улучшения: цены, максимум 5, характеристики растут (юнит + вручную в святилище)
- [x] Побочное задание от NPC, награда при выполнении (авто + юнит)
- [x] Маяк → портал → следующий уровень (авто)
- [x] Маяк без осколков — отказ с количеством (авто)
- [x] Победа и экран статистики (авто)
- [x] Гибель → «Возродиться у святилища» (авто)
- [x] Достижения открываются один раз и видны в меню (юнит + вручную)
