# Чек-лист дизайна уровней

Пункты 1–6 проверяются автоматически для каждой карты (`tests/levels.test.ts`), в том числе для новых.

- [x] Карта прямоугольная, нет неизвестных символов (авто)
- [x] Один старт, один маяк, один NPC, минимум одно святилище (авто)
- [x] Осколков хватает для маяка (с учётом осколка босса) (авто)
- [x] Все цели достижимы с учётом ключей и дверей (авто)
- [x] Объекты не отрезают проходимые клетки (авто, нашёл BUG-005)
- [x] Враги не замурованы (авто)
- [x] Ручей в лесу пересекается только по мостам (вручную, визуально)
- [x] Освещение позволяет различать путь в склепе (вручную, визуально)
- [ ] Сложность растёт плавно от уровня к уровню (нужен плейтест человеком)
- [ ] Нет «мёртвых» зон, куда незачем идти
