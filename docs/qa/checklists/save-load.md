# Чек-лист сохранений

- [x] Автосохранение при входе на уровень (авто)
- [x] Автосохранение у святилища («Отдохнуть»), после маяка и смерти босса (вручную + по коду)
- [x] Сохранение в слоты 1–3, автослот только для чтения (авто + вручную)
- [x] «Продолжить» берёт самое свежее корректное сохранение (авто + юнит)
- [x] Загрузка восстанавливает уровень, инвентарь, улучшения, задания, статистику (авто + юнит)
- [x] Подобранные предметы, открытые двери и сундуки остаются такими после загрузки (вручную)
- [x] Босс не воскресает, его осколок лежит, если не подобран (вручную)
- [x] Битый JSON → «Повреждено: Файл сохранения повреждён» (авто)
- [x] Изменённые вручную данные → «Контрольная сумма не совпадает» (авто + юнит)
- [x] Сохранение из будущей версии отклоняется (юнит)
- [x] Сохранение версии 1 мигрирует (юнит)
- [x] Значения вне диапазонов ограничиваются (юнит + фаззинг 500 входов)
- [x] Формат соответствует JSON Schema (контрактный тест)
- [x] Настройки сохраняются отдельно от партии (авто)
- [x] localStorage недоступен (приватный режим) → игра работает, хранит в памяти (юнит)
- [ ] Переполнение localStorage при сохранении → сообщение «Не удалось сохранить»
