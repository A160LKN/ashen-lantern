# Чек-лист звука

Звук синтезируется в браузере (WebAudio), автоматически проверить звучание нельзя. **На слух чек-лист не проходился** —
в окружении тестирования не было возможности слушать звук. Автотест проверяет работу движка: контекст запущен, у уровня
свой трек и фон, музыкальный секвенсор работает.

- [ ] До первого нажатия звука нет (политика браузеров), после — играет музыка меню
- [ ] У каждого уровня своя музыка; в бою с боссом — быстрая боевая; после победы — мажорная
- [ ] Шаги при ходьбе, при беге чаще
- [ ] Удар мечом, попадание, крит, получение урона, смерть врага звучат по-разному
- [ ] Подбор монеты, предмета, осколка; сундук, дверь, маяк, портал
- [ ] Фоновые звуки: ветер и сверчки в лесу, капли в склепе, гул и треск в цитадели
- [ ] Громкость музыки и эффектов меняется независимо; 0% — тишина
- [ ] Звук не «копится»: десятки монет подряд не дают перегрузки (стоит ограничение частоты)
- [ ] Вкладка в фоне → возврат: музыка не проигрывает пропущенные ноты разом
