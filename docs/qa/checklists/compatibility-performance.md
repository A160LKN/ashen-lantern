# Чек-лист совместимости и производительности

## Браузеры
- [x] Chromium — все E2E (локально и в CI)
- [x] Firefox — все E2E (CI, Ubuntu); там нет WebGL и игра работает через Canvas-рендерер
- [x] Без WebGL (Canvas-рендерер): мир, освещение и HUD отображаются, 60 FPS (Chromium с `--disable-webgl`, вручную по скриншоту)
- [ ] Safari / WebKit — не проверялось
- [ ] Реальные Chrome/Edge/Firefox на Windows — не проверялось

## Экраны
- [x] 1280×720 (E2E), 960×540, 800×600 (вручную)
- [ ] 4K, ультраширокие мониторы
- [ ] Изменение размера окна во время игры

## Производительность
- [x] Стоимость кадра ≈ 0,3 мс CPU (синхронный прогон 300 кадров в Chromium)
- [x] FPS выше порога в CI (E2E «стабильная частота кадров»; значение записывается в отчёт)
- [ ] 60 FPS на типичном ПК в видимой вкладке (замер человеком)
- [ ] Нет роста памяти за 30 минут игры
