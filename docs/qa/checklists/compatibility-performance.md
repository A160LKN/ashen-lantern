# Чек-лист совместимости и производительности

## Браузеры
- [x] Chromium — все E2E (локально и в CI)
- [x] Firefox — все E2E (CI, Ubuntu); там нет WebGL и игра работает через Canvas-рендерер
- [x] Без WebGL (Canvas-рендерер): мир, освещение и HUD отображаются, 60 FPS (Chromium с `--disable-webgl`, вручную по скриншоту)
- [ ] Safari / WebKit — не проверялось
- [ ] Реальные Chrome/Edge/Firefox на Windows — не проверялось

## Экраны
- [x] 1280×720 (E2E), 960×540, 800×600 (вручную)
- [ ] 4K, ультраширокие мониторы
- [x] Изменение размера окна во время игры (авто: 640×480 → 1600×900)

## Производительность
- [x] Стоимость кадра ≈ 0,3 мс CPU (синхронный прогон 300 кадров в Chromium)
- [x] Игровая логика (ИИ, поиск пути, физика) < 4 мс на кадр — E2E «игровая логика укладывается в бюджет кадра»; локально 0,04 мс
- [x] FPS записывается в отчёт E2E справочно. Жёстко не проверяется: в CI WebGL программный, и FPS там отражает машину (на медленном раннере было 19,4)
- [ ] 60 FPS на типичном ПК в видимой вкладке (замер человеком)
- [x] Нет утечек за 5 минут игрового времени с боем: память 21 МБ без роста, объекты сцены уменьшаются вместе с убитыми врагами (нагрузочный прогон через тестовый API). 30 минут реального времени человеком не проверялись
