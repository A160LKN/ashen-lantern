# Тест-план

## 1. Объект тестирования

«Пепельный Фонарь» — браузерная 2D action-RPG (Phaser 3, TypeScript). Три уровня, враги с ИИ на конечных автоматах,
босс с двумя фазами, прогрессия, сохранения в localStorage, процедурная графика и звук.

## 2. Объём

**Тестируется:**

| Область | Что именно |
| --- | --- |
| Запуск и меню | загрузка без ошибок, первое нажатие (разблокировка звука), все пункты меню |
| Управление | WASD/стрелки, бег (Shift) и выносливость, удар (Пробел/ЛКМ), E, Q, I/Tab, Esc |
| Мир и коллизии | стены, деревья, вода, лава, объекты; достижимость всех целей на картах |
| Бой | попадание дуги удара, урон и криты, отбрасывание, неуязвимость после удара, смерть |
| ИИ врагов | патруль, обнаружение по видимости, погоня по пути A*, атака, потеря цели, возврат |
| Босс | пробуждение, приёмы обеих фаз, призыв, смерть, выпадение осколка |
| Лут и инвентарь | монеты (магнит), зелья (лимит 9), масло, ключи, осколки, сундуки, горшки |
| Прогрессия | опыт и уровни, улучшения и цены, задания и награды, достижения |
| Переходы | маяк → портал → следующий уровень, победа, поражение и возрождение |
| Сохранения | автосохранение, 3 слота, загрузка, удаление, повреждённые и устаревшие файлы, миграция |
| Настройки | громкость музыки и эффектов, тряска, FPS, сложность; сохранение после перезагрузки |
| Интерфейс | HUD, подсказки, диалоги, уведомления, полоса босса, оверлеи, навигация с клавиатуры |
| Звук | музыка уровней и босса, эффекты действий, фоновые звуки, раздельная громкость |
| Производительность | частота кадров, стоимость кадра |

**Не тестируется:** мобильные устройства и сенсорный ввод, геймпад (не поддерживаются), Safari (нет в окружении),
локализация на другие языки (игра только на русском), нагрузка — у игры нет сервера.

## 3. Подход

Пирамида тестов адаптирована под игру:

| Уровень | Что проверяет | Инструмент | Где запускается |
| --- | --- | --- | --- |
| Статические проверки | типы, стиль, частые ошибки | TypeScript strict, ESLint | CI |
| Юнит | чистая логика: прогрессия, задания, A*, видимость, FSM, лут | Vitest | CI |
| Данные уровней | все цели достижимы, объекты не перекрывают проходы, враги не замурованы | Vitest + BFS | CI |
| Контракт | файл сохранения соответствует JSON Schema; фаззинг очистки данных | Vitest + Ajv | CI |
| E2E | сквозные сценарии в настоящем браузере на production-сборке | Playwright | CI, Chromium и Firefox |
| Ручное | визуал, освещение, читаемость, звук, ощущение управления, исследовательские сессии | браузер, DevTools | локально |

Логика, не зависящая от движка, вынесена в отдельные модули именно ради юнит-тестов: так быстрые тесты покрывают
правила игры, а E2E проверяют только связки.

**Техники тест-дизайна:** классы эквивалентности и граничные значения (лимит зелий 9, уровни улучшений 0–5,
громкость 0–100%, индекс уровня 0–2), таблицы решений (взаимодействие с маяком: осколков хватает / не хватает /
маяк горит / последний уровень), переходы состояний (ИИ врага, оверлеи и пауза, жизненный цикл сохранения),
попарное тестирование настроек, исследовательское тестирование по сессиям.

## 4. Окружения

| Окружение | Где |
| --- | --- |
| Chromium (Playwright 1.65) | локально (macOS) и CI (Ubuntu) |
| Firefox (Playwright) | CI (Ubuntu); локально не запускается из-за ограничений песочницы |
| Встроенный браузер на Chromium | ручные проверки, 960×540 и 800×600 (letterbox) |

## 5. Критерии

**Начало тестирования сборки:** сборка проходит `npm run build`, игра открывается и показывает меню.

**Готовность к выпуску:**
- линтер, типы, юнит- и E2E-тесты зелёные в обоих браузерах;
- покрытие логики не ниже порогов (строки 90%, ветви 85%, функции 90%);
- нет открытых дефектов S1–S2, известные S3 описаны в отчёте;
- чек-лист смоука пройден на сборке, которая уходит на Pages.

## 6. Риски

| Риск | Вероятность | Влияние | Что делаем |
| --- | --- | --- | --- |
| Уровень нельзя пройти из-за ошибки в карте | средняя | критическое | автотест достижимости для каждой карты |
| Потеря или порча сохранения | низкая | критическое | контрольная сумма, схема, фаззинг, миграция, E2E с битыми файлами |
| Нестабильные E2E из-за реального времени | высокая | среднее | пошаговые кадры через тестовый API, ожидания по условию, а не по таймеру |
| Различия браузеров в WebGL и вводе | средняя | среднее | E2E в Chromium и Firefox |
| Падение при уничтожении объектов посреди эффектов | средняя | высокое | E2E полного боя с боссом, отсутствие ошибок в консоли проверяется в смоуке |
| Звук нельзя проверить автоматически | высокая | низкое | ручной чек-лист звука |

## 7. Результаты работы

Тест-кейсы, чек-листы, баг-репорты, матрица трассировки, отчёт о тестировании, отчёты Playwright и покрытия
в артефактах CI.
