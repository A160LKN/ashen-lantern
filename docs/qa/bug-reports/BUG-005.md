# BUG-005 · В лесу две жаровни замуровали клетку у маяка

| Поле | Значение |
| --- | --- |
| Severity / Priority | S4 Minor / P3 (дефект дизайна уровня) |
| Область | Уровень 1 «Тлеющий лес» |
| Воспроизводимость | Всегда |
| Статус | Исправлен (`ee17bad`) |

**Как найден:** автотест `tests/levels.test.ts` «объекты-препятствия не перекрывают единственный проход» упал:
`expected 1 to be 0`.

**Фактический результат:** клетка (38,12) справа от маяка окружена жаровнями (38,11) и (38,13), маяком (37,12) и краем
карты (39,12). Попасть туда нельзя.

**Ожидаемый результат:** каждая проходимая клетка, доступная без объектов, доступна и с ними.

**Исправление:** жаровни перенесены на (36,11) и (36,13) в `src/data/levels.ts`.

**Регресс:** тот же автотест, кейс TC-WORLD-03. Проверка выполняется для всех уровней, в том числе новых.
