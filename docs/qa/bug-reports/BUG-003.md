# BUG-003 · Полоса босса перекрывает цифры здоровья в HUD

| Поле | Значение |
| --- | --- |
| Severity / Priority | S4 Minor / P3 |
| Область | Интерфейс |
| Воспроизводимость | Всегда во время боя с боссом |
| Статус | Исправлен (`ee17bad`) |

**Шаги**
1. Начать бой с Пепельным Королём.
2. Посмотреть на полосу здоровья героя в левом верхнем углу.

**Фактический результат:** надпись с цифрами здоровья поверх красной полосы пропадает, видна только полоса.

**Ожидаемый результат:** цифры здоровья видны всегда.

**Причина:** чтобы полоса босса была поверх своей рамки, весь слой графики HUD поднимался наверх (`bringToTop`) — вместе
с полосами героя, которые закрывали текст.

**Исправление:** полоса босса рисуется на отдельном графическом слое (`src/scenes/UIScene.ts`).

**Проверка:** ручной кейс TC-UI-03.
