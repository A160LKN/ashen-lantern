# BUG-012 · Подписки на события копятся при каждом перезапуске сцены

| Поле | Значение |
| --- | --- |
| Severity / Priority | S4 Minor / P3 (утечка) |
| Область | Сцены, жизненный цикл |
| Воспроизводимость | Всегда |
| Статус | Исправлен |

**Как найден:** ревью кода — подписка `this.events.on(RESUME, …)` в `create()` без отписки.

**Шаги**
1. Начать игру.
2. Перезапустить игровую сцену 5 раз (так происходит при переходе на уровень, гибели и загрузке).
3. Посчитать подписки: `scene.events.listenerCount('resume')`.

**Фактический результат:** 6 подписок вместо одной. При каждом возврате из паузы обработчик вызывается столько раз,
сколько раз перезапускалась сцена. То же в главном меню (каждый возврат в меню) и в экранах святилища, сохранения и
инвентаря (каждая перестройка экрана).

**Ожидаемый результат:** одна подписка, независимо от числа перезапусков.

**Причина:** подписки через `scene.events` переживают `scene.restart()` — Phaser не снимает их автоматически.

**Исправление:** функция `onSceneEvent` (`src/ui/widgets.ts`) снимает подписку при остановке сцены; в оверлеях подписка
создаётся один раз за запуск, а не при каждой перестройке.

**Регресс:** E2E «Подписки на события не копятся при перезапуске сцен»: без исправления `resume: 6`, с ним `1`.
Проверены и подписки на мышь в игре и HUD — их Phaser снимает сам, они не растут.
