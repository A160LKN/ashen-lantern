# BUG-006 · Притянутая монета улетает за пределы карты

| Поле | Значение |
| --- | --- |
| Severity / Priority | S3 Major / P2 |
| Область | Лут |
| Воспроизводимость | Всегда, если отойти, пока монета летит |
| Статус | Исправлен (`f1c7952`) |

**Шаги**
1. Уровень 1. Положить монету в 30 px от героя: она начинает лететь к нему.
2. Через 4 кадра отойти на 8 клеток (воспроизводилось телепортом через тестовый API, в игре — бегом).
3. Подождать 2 с.

**Фактический результат:** монета продолжает лететь с последней скоростью и вылетает за карту: позиция (−68, 273), скорость
(−130, 22). Ширина карты 640 px. Монета потеряна.

**Ожидаемый результат:** вне радиуса магнита (42 px) монета останавливается.

**Причина:** скорость задавалась только внутри радиуса и никогда не сбрасывалась.

**Исправление:** функция `magnetVelocity` (`src/world/loot.ts`) возвращает ноль вне радиуса; монеты ещё и не выходят за
границы мира.

**Проверка:** повторный прогон — монета остановилась на (190, 230), скорость (0, 0).
**Регресс:** `tests/loot.test.ts` «магнит монет»; кейс TC-INT-06.
