# BUG-004 · Быстрое повторное нажатие в святилище игнорируется

| Поле | Значение |
| --- | --- |
| Severity / Priority | S3 Major / P2 |
| Область | Интерфейс, святилище |
| Воспроизводимость | Всегда, если второе нажатие раньше чем через 150 мс |
| Статус | Исправлен (`ee17bad`) |

**Шаги**
1. Открыть святилище, монет хватает на улучшение.
2. Купить улучшение (Enter) и сразу выбрать «Отдохнуть и сохранить» (Enter).

**Фактический результат:** покупка проходит, отдых — нет: здоровье осталось 10, контрольная точка `null`.

**Ожидаемый результат:** выполняются оба действия.

**Причина:** меню игнорирует ввод первые 150 мс, чтобы нажатие, открывшее экран, не активировало пункт. Экран святилища
перестраивается после каждой покупки, и задержка включалась заново.

**Исправление:** при перестройке того же экрана задержка не применяется (`instant` в `MenuList`, `src/ui/widgets.ts`).
Так же исправлены экраны сохранения и инвентаря.

**Проверка:** после исправления: здоровье 99, контрольная точка `{x: 56, y: 376}`, «Прогресс сохранён»; кейс TC-UI-04.
