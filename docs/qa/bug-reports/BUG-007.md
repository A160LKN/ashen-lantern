# BUG-007 · Предмет, выпавший у стены, оказывается в стене и недоступен

| Поле | Значение |
| --- | --- |
| Severity / Priority | S3 Major / P2 |
| Область | Лут, коллизии |
| Воспроизводимость | ≈ 20% выпадений рядом со стеной |
| Статус | Исправлен (`f1c7952`) |

**Шаги**
1. Уровень 1. Создать 300 выпадений зелья в клетке (1,12), вплотную к деревьям на краю карты (тестовый API).
2. Подождать окончания разлёта.
3. Пройти вдоль стены, пытаясь подобрать предметы.

**Фактический результат:** 60 из 301 зелья лежат внутри непроходимых клеток. Ни одно из них не подобралось при проходе
вдоль стены. В игре так теряются зелья и масло, выпавшие из врагов и сундуков у стен.

**Ожидаемый результат:** предметы падают только на проходимые клетки.

**Причина:** точка разлёта выбиралась случайно в прямоугольнике ±14×±10 px без проверки проходимости.

**Исправление:** `findDropPosition` (`src/world/loot.ts`) выбирает точку только на проходимой клетке; если такой нет,
предмет остаётся в точке выпадения.

**Проверка:** повторный прогон — 0 из 301 в стене.
**Регресс:** `tests/loot.test.ts` — 2000 выпадений у стены, ни одного в стене; кейс TC-INT-07.
