# BUG-002 · Игра падает с TypeError после смерти босса

| Поле | Значение |
| --- | --- |
| Severity / Priority | S1 Blocker / P1 |
| Область | Босс, эффекты |
| Воспроизводимость | Всегда |
| Статус | Исправлен (`ee17bad`) |

**Шаги**
1. Уровень 3 «Цитадель Пепла», войти в тронный зал.
2. Победить Пепельного Короля.

**Фактический результат:** через ≈ 140 мс после смерти игра останавливается. В консоли:
```
Uncaught TypeError: Cannot read properties of undefined (reading 'center')
    at get cx (Enemy.ts:70)
    at TimerEvent.callback (GameScene.ts:758)
```
Флаг `bossDefeated` уже успел сохраниться, поэтому после перезагрузки босса нет.

**Ожидаемый результат:** серия вспышек, выпадает осколок, игра продолжается.

**Причина:** отложенные вспышки (`delayedCall`) читали `e.cx` у объекта босса, который к тому моменту уже уничтожен
(`body === undefined`).

**Исправление:** координаты фиксируются до уничтожения (`src/scenes/GameScene.ts`, `onBossDefeated`).

**Регресс:** E2E «босс: пробуждение, полоса здоровья, победа и финальный экран» (смоук отдельно проверяет отсутствие
ошибок в консоли); кейсы TC-BOSS-04, TC-BOSS-05 — заодно проверено, что осколок восстанавливается после перезагрузки.
