# BUG-001 · Чёрный экран: холст нулевого размера при запуске в скрытой вкладке

| Поле | Значение |
| --- | --- |
| Severity / Priority | S2 Critical / P1 |
| Область | Запуск, масштабирование |
| Воспроизводимость | Всегда, если вкладка или панель скрыта в момент загрузки |
| Статус | Исправлен (`ee17bad`) |

**Шаги**
1. Открыть игру в фоновой (скрытой) вкладке.
2. Переключиться на вкладку.

**Фактический результат:** чёрный экран. Игра работает (`game.loop.actualFps` ≈ 142, активна сцена Menu), но у холста
CSS-размер `0px × 0px`.

**Ожидаемый результат:** меню видно сразу, холст вписан в окно.

**Причина:** Phaser считает размер контейнера один раз при старте; у скрытой вкладки он равен 0, а события `resize` при
показе вкладки не приходит.

**Исправление:** `ResizeObserver` на контейнере и пересчёт масштаба после события `READY` (`src/main.ts`).

**Проверка:** после `scale.refresh()` холст 1024×576 при окне 1024×768; ручной кейс TC-BOOT-06.
