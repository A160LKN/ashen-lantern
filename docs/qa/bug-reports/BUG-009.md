# BUG-009 · При полной сумке зелье молча не подбирается

| Поле | Значение |
| --- | --- |
| Severity / Priority | S4 Minor / P3 (удобство) |
| Область | Лут, интерфейс |
| Воспроизводимость | Всегда при 9 зельях |
| Статус | Исправлен (`f1c7952`) |

**Как найден:** граничное значение лимита зелий (`MAX_POTIONS = 9`).

**Шаги**
1. Иметь 9 зелий.
2. Наступить на зелье.

**Фактический результат:** ничего не происходит: зелье остаётся на земле без звука и сообщения. Похоже на сломанный
подбор.

**Ожидаемый результат:** понятное сообщение о причине.

**Исправление:** сообщение «Сумка полна: больше 9 зелий не унести», не чаще раза в 3 с, чтобы не спамить, пока герой стоит
на предмете.

**Проверка:** сообщение появилось в HUD; кейс TC-INT-08.
